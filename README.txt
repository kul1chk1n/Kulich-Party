КУЛИЧ — 20 | ПРИГЛАШЕНИЕ

Форма анкеты работает через PHP + JSON + Telegram.

1) 2ГИС
Встроенная карта удалена. В разделе «Место» оставлена только кнопка «ОТКРЫТЬ В 2ГИС →».

2) Telegram
ВАЖНО: токен, который ранее был отправлен в чат, раскрыт. Создайте НОВЫЙ токен через BotFather и не публикуйте его.

Откройте config.php и заполните:
- TELEGRAM_BOT_TOKEN — новый токен бота;
- TELEGRAM_CHAT_ID — ваш chat_id;
- ADMIN_PASSWORD — пароль для admin.php.

Как получить chat_id:
1. Откройте бота и нажмите Start / отправьте /start.
2. В браузере откройте официальный метод getUpdates для своего бота.
3. Найдите в JSON блок message -> chat -> id. Это ваш TELEGRAM_CHAT_ID.

Если у бота уже настроен webhook, getUpdates не работает, потому что эти способы получения обновлений взаимоисключающие. В таком случае webhook нужно временно отключить.

3) Форма
Посетитель заполняет ФИО, участие, +1, имя +1, ночёвку, напитки и комментарий. Браузер отправляет JSON на api.php.
api.php сохраняет каждую анкету в data/responses.json и отправляет уведомление в Telegram.

4) Админка
Откройте /admin.php и введите ADMIN_PASSWORD.
Список автоматически сортируется по ФИО. Кнопка «Скачать Word» формирует Word-файл.

5) Хостинг
Нужен обычный PHP-хостинг с cURL. Загрузите весь проект. Убедитесь, что папка data доступна PHP для записи. .htaccess закрывает config.php и responses.json от прямого просмотра.

6) Проверка
Сначала отправьте тестовую анкету сами. Проверьте:
- появилась ли запись в admin.php;
- пришло ли сообщение в Telegram;
- формируется ли Word.

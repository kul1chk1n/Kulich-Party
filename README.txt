САЙТ-ПРИГЛАШЕНИЕ НА ДЕНЬ РОЖДЕНИЯ

Файлы:
- index.html — структура сайта
- style.css — дизайн и адаптивность
- script.js — обратный отсчёт, анкета, карта

Как запустить:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для публикации загрузите три файла на любой обычный статический хостинг.

Что нужно заменить в script.js:
EVENT_DATE — точная дата и время.
MAP_URL — ссылка на точку коттеджа.
HOST_NAME — имя именинника.

В index.html:
- [ ИМЯ ]
- [ НАЗВАНИЕ КОТТЕДЖА ]
- [ АДРЕС / ЛОКАЦИЯ ]
- тексты программы и дресс-кода.

Анкета сейчас демонстрационная: ответы сохраняются в localStorage браузера.
Для реального сайта можно подключить Telegram-бота, Google Sheets, Firebase или PHP/MySQL.
